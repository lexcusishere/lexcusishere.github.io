Profile assets served from this origin so the GitHub profile does not depend on rate limited third party cards. Every number is generated from the GitHub API at render time.

STATICS

WHAT THIS IS

Generated, not hand written

gen_assets.py reads the GitHub API and rewrites the three SVGs: commits, pull requests, issues, repositories, stars, yearly contributions and the daily calendar.

Readable without animation

Text is static. Motion is limited to a decorative rule and a status dot, and the stylesheet disables it under prefers-reduced-motion.

Served as SVG

GitHub serves raw repository files as text, so an SVG in a repo will not render through an image tag. Served from Pages it arrives as image/svg+xml.

Source data: github.com/lexcusishere. Refresh runs on a timer, last build timestamp is inside each card.
